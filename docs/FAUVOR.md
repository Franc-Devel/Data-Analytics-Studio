# FAUVOR Analytics

## Rol dentro del catálogo

Análisis de datos e inteligencia comercial.

Incluye un dashboard Streamlit, módulos de análisis e interfaces de escritorio. Los gráficos utilizan la paleta FAUVOR y las vistas conservan sus datos y cálculos.

## Identidad

El nombre visible del producto es **FAUVOR Analytics**. Se conserva la URL `Franc-Devel/Data-Analytics-Studio` para mantener los enlaces históricos. El símbolo y los iconos provienen del kit original FAUVOR. La paleta utiliza marfil, blanco cálido, bronce y dorado; los estados positivos usan un oliva sobrio.

Las portadas son ilustraciones conceptuales, no capturas de pantalla. No acreditan clientes, cifras de uso, resultados comerciales ni funciones que no estén implementadas.

## Ejecución

Usá las instrucciones y requisitos del README para Streamlit o la interfaz de escritorio. La comprobación realizada en esta actualización fue sintáctica; no se ejecutó la aplicación con archivos privados.

## Alcance y límites

La demo de la landing utiliza ejemplos y no está conectada a los archivos, bases, servicios de WhatsApp ni cuentas reales del servidor.

FAUVOR Flow es un proyecto independiente. No conecta automáticamente estas bases o servicios: cualquier integración futura debe implementarse y verificarse.

## Validación de esta actualización

Se revisaron los archivos de identidad y documentación. Las compilaciones React de Taller, Gaming y Clima pasaron en la sesión. La sintaxis Python de Analytics se comprobó. La revisión visual en navegador y las integraciones externas no se verificaron en este entorno.
